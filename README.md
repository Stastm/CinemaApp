# CinemaApp

Android-приложение для выбора фильма и билета в кино.

## Возможности

- Просмотр списка фильмов
- Страница фильма: [описание, постер, рейтинг, длительность]
- Выбор сеанса: [дата и время]
- Выбор мест в зале
- Оформление билета и [просмотр своих билетов]

## Технологии

- Java
- [Jetpack Compose или XML-разметка: что у вас]
- [Room / Firebase / API: откуда берутся данные о фильмах и сеансах]
- Архитектура: [MVVM]

## Запуск

1. Откройте проект в Android Studio.
2. [Если используется Firebase: добавьте свой файл google-services.json в папку app/.]
3. Запустите приложение на эмуляторе или телефоне.
